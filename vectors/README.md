# Test vectors of core v2

Documents of major version 3 (`@context` = `urn:keysingate:core:v3`).
Generated by `cargo run -p ksg-vectors-v2`. **Not edited by hand.** A re-run
yields byte-identical files: `ksg-vectors-v2/tests/determinism.rs` checks it,
and `tests/replay.rs` reads the files back and verifies the documents they
carry to the verdicts they state — the way another implementation uses them.

Every value is computed by calls into `ksg-core-v2`. A refusal carries the
core's reason as text; another implementation must match the **verdict**, the
wording is ours.

**The vector reader** (sets 09–11): anchors of kind `urn:ksg:anchor:vector`
are read; the proof is the UTF-8 of the moment the network proves; the proof
`forged` is refused; every other kind is not read. It stands in for a network
reader so the time rule can be checked without a network.

External Certificate Transparency values for the tree are checked separately,
in `crates/ksg-core-v2/tests/ct_vectors.rs`.
